# Images Directory

This directory contains the images used in the portfolio website.

## Required Images

Please add the following images to this directory:

1. **profile.jpg** - Your professional headshot photo (the third attachment from your original request)
   - Recommended size: 500x500 pixels minimum
   - Format: JPG or PNG
   - This will be displayed as a circular profile image

2. **hero-bg.jpg** - The hero section background image (the second attachment - technology/gaming themed banner)
   - Recommended size: 1920x1080 pixels
   - Format: JPG or PNG
   - This will be used as the background for the top section of the website

## How to Add Images

1. Save your profile photo as `profile.jpg` in this directory
2. Save the technology banner as `hero-bg.jpg` in this directory
3. The website will automatically display these images

## Image Optimization Tips

- Keep file sizes under 500KB for faster loading
- Use JPG format for photographs
- Use PNG format for images with transparency
- Ensure images are high resolution but compressed for web use
